## 正式主图交接约定

E 的联调通过 F 的 CLI 或调用同一入口的 WebUI。旧版 B 文件交接原型已移除。接入时由 F 同步节点、产物规格和清单契约。

- **英文字幕留在任务内。** B 产生英文 SRT 初稿和结构化分段。C 从分段读取 `segment_id`、原文和时间轴，执行翻译初稿、审校、定向修正与有限次数复审。英文 SRT 可作为内部校对副本。C 用结构化分段保留说话人和时间戳，审校通过后再交 E。
- **正式输入。** 从 `segments/segments.json` 读英文和毫秒时间戳，从 `translated/reviewed_blocks.json` 读审校后的 `zh_subtitle`。按片段 ID 配对并检查缺段、重复与越界。D 交付已对齐的 VoxCPM2 中文配音与背景声混合整轨，E 核对音轨与原片时长、声道和起点，再用 FFmpeg 替换原混音。
- **字幕压制与封面分开。** E 将通过审校的中文与 B 的英文按 ID 关联，生成内部双语 SRT。根据用户选择的模板和输入画面尺寸生成带中英样式的 ASS。FFmpeg 用 ASS 烧录画面，同时保留既定的配音音轨处理。以输入视频流的平均码率作为重编码目标，并保留分辨率、宽高比和帧时间轴。实测码率可能有偏差，验收时同时记录源值和输出值。有可用源视频流码率时采用两遍编码。取不到可用的源视频流码率时使用 CRF 20，并记录回退和输出实测值。
- **封面默认关闭。** 本地视频勾选后由用户提供原封面。YouTube 链接勾选后从同一视频的元数据获取缩略图。用 OCR 或视觉模型检查有无待翻译文字。有则调用可配置的图像编辑模型，将原文字换成中文并尽量保留画面、构图和字体风格。无待翻译文字则原样保留图片字节、尺寸和格式，跳过编辑请求。因为原图可能是 JPEG、PNG 或 WebP，正式产物路径需支持实际扩展名。
- **WebUI 联调。** 「运行」已通过 F 的 CLI 调用正式主图。继续配合 F 对接节点配置。字幕、封面和配音的界面配置在对应后端参数正式接入后展示。字幕查看页读取已落盘的英文分段、初译和审校产物，发布包从结果节点获取。
- **发布包汇合。** F 汇总压制后的成片和封面分支。封面关闭时，清单省略封面。封面开启时，展示封面结果或失败原因。最终结果统一展示发布包，英文和双语 SRT、ASS 留在任务目录供处理和排查。

建议先落地模板选择、双语 SRT 到 ASS 和 FFmpeg 参数保留，再做独立封面适配，最后由 F 将两个分支接入结果汇总。首轮用横屏 720p、1080p 和 2160p 短视频检查样式与码率，用有文字和无文字的原封面检查编辑与原样保留行为。

## 批量制作 ASS 样张

`config/subtitle_styles.json` 定义四款 ASS 风格和共享的 2160p 排版基准。节点从 `config/subtitle_cover.toml` 读取工作台保存的风格和语言排布，输出 `subtitles/burnin.ass`。可用以下命令生成样张。

```bash
uv run --locked python -m project.subtitle_templates --output jobs/subtitle-style-samples
```

命令生成 60 份带示例字幕的 ASS。可加 `--font-name` 指定本机已安装的字体名称，然后用 Aegisub 或 FFmpeg 逐类预览。每款风格有 `zh_only`、`zh_top`、`zh_bottom` 三种排布。内部双语 SRT 保留中文在上、英文在下，画面上的语言顺序由 ASS 决定。

画面高度向上匹配 480p、720p、1080p、1440p 或 2160p，超过 2160p 时使用 2160p 档。字号、描边、阴影和垂直边距随档位缩放，ASS 脚本宽度和水平边距按原画面宽高比计算。首版验收横屏。

默认样式沿用样稿的 MiSans Medium 和 MiSans。烧录机需要安装 ASS 文件所引用的字体。
