- [ ] **统一运行入口。** WebUI 服务端已调用同一个 CLI 入口，并读取约定的目录、日志和产物。下一步确认向界面暴露哪些真实节点进度与参数。CLI 用于开发联调和排错。先跑通 B→C，再接上 D 和 E。对照真实产物报告完成状态，mock 流转单独记录。
- [ ] **登记新增能力。** 将 VoxCPM2 音色克隆、背景分离和重混、超时定向返工、WebUI 正式图接入登记为增量。与 B–E 确认参考音频的归属、复核状态、时长日志以及 D→E 的整轨交接，再更新共享产物约定。
