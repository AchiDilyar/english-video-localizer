# 基于多智能体协作的英文视频本地化系统 · WebUI

## 启动

从仓库根目录运行，无需 Node.js 构建、前端依赖安装或模型密钥。

```bash
uv run --locked --extra b-asr python scripts/serve_workflow_ui.py
```

浏览器打开 `http://127.0.0.1:8765/`。如端口已占用，可使用 `--port 8766`，并打开对应地址。升级后需重启 WebUI 服务，浏览器再刷新。

服务仅监听 `127.0.0.1`。打开地址直接进入单一工作台。深浅主题跟随系统外观。

## 运行工作流

在「视频输入」选择本地 MP4、填写 YouTube 链接，或选择「已有素材」。原片只保留在首次素材目录，任务通过 --input <原视频绝对路径> 读取，不复制或硬链接到任务目录。链接重复提交时校验并复用已有文件，不再重复下载。浏览器本地文件首次上传至共享素材目录；之后选择已有素材无需再次上传。处理结果仍保存在各自 jobs/<任务ID>/ 下，旧任务的原片仍可原地预览。

每次执行一个任务，上传上限 2 GiB。工作台显示运行状态和已生成的节点产物。新任务通过 CLI 的 --report-progress 记录 LangGraph 实际节点事件，可显示并行节点和空增量；历史任务没有该日志时兼容按正式产物显示就绪状态。底部「后端控制台」实时读取 CLI 的 stdout 和 stderr（任务目录中的 `logs/runner.log`）。任务队列也可以打开历史任务的后端日志。「清空」只清除当前显示，磁盘保留完整日志。

每张节点卡片显示后端配置的运行模式。「模拟」和「真实」分别对应 `config/mock.toml` 中的 `true` 和 `false`。「字幕压制准备」对应主图的 `subtitle_cover`。CLI 在运行开始时把同一配置下的节点模式写到终端和任务日志。 右键节点卡片可单独切换模式，聚焦节点标题后也可按 Shift+F10。卡片上的标记显示当前模式。模拟节点的卡片、步骤按钮和导航图使用中性灰。模拟卡片还会显示强调色提示「模拟节点：此处配置不影响运行结果」。保存会更新本机仓库的共享配置，下次运行生效。工作台检查真实实现和上游模式，并在任务运行时禁用切换。

当前启用的真实节点以本机 `config/mock.toml` 为准。CLI 成功退出且已生成非空 `video/final.mp4` 时，工作台显示完成，控制台和任务队列都提供 MP4 下载。主图跑完但没有生成成片时，显示「工作流已停止」。「字幕压制准备」以非空的 `subtitles/burnin.ass` 为完成标志。节点同时在该目录生成原文、译文和双语 SRT。接真实节点时由 F 维护节点开关，B/C 的环境、模型和凭据按各自模块文档准备。 [主图文档](graph/README.md) · [B 环境说明](nodes/asr_diarize/environment/README.md)

## 字幕查看

在工作流中选好本地 MP4，或链接任务完成原片下载后，切到顶部「字幕查看」即可播放源视频。运行时会关联当前任务，右侧默认显示断句后的英文、首次翻译和反思式终版。有首次分句文件的历史任务还会显示「首次分句」。点击字幕块会跳到它的开始时间。播放和拖动进度条会高亮当前字幕，勾选「跟随播放」时列表也会自动滚动。

| 阶段 | 读取来源 |
| --- | --- |
| 首次分句（历史任务） | 历史任务已保存的 `b/initial.srt` |
| 断句处理后 | `subtitles/english_segmented.srt`、历史任务的英文 SRT，或 `segments/segments.json` |
| 首次翻译 | 按分段 ID 对齐 `segments/segments.json` 与 `translated/translated_blocks.json` |
| 反思式终版 | `subtitles/bilingual.srt`，或按分段 ID 合并 `segments/segments.json` 与 `translated/reviewed_blocks.json` |

双语 SRT 沿用每块第一行为中文、后续行为英文的约定。各阶段从任务目录读取现有产物，文件未生成时显示未就绪。WebUI 按团队的产物规格表定位并校验结构化文件。

这个页面替代在工作台中单独打开 B 的字幕查看页。每个阶段通过本地 JSON 读取接口展示时间轴，SRT 文件留在任务目录。浏览器会在当前会话恢复最近一次运行任务的视频和字幕。选取另一段视频后会切换上下文，避免把上一任务的字幕配到新视频上。

## 本版可以做什么

- 主图的 8 个节点按预设位置展开。视频输入、转写、分块、初译和审校依次执行。审校结果并行进入配音与字幕准备，合成视频等待两条分支完成。连线默认用一条贝塞尔曲线直接连接源节点的输出端口和目标节点的输入端口，经过其他节点时由卡片遮盖。步骤导航可直接定位节点。
- 鼠标移到连线上，右键添加锚点。拖动圆形锚点调整曲线，再右键该锚点可删除。锚点随项目 JSON 保存，也可撤销或重做。
- 拖动节点标题移动节点，拖动右下角调整宽高。聚焦尺寸手柄后可用方向键微调。拖动空白可平移画布，滚轮可缩放。
- 点击顶部「运行」左侧的「任务队列」，从页面右侧打开抽屉。
- 拖动导航图中的视口框平移画布。画布工具栏还提供总览、定位选中、100% 缩放和全屏。点击画布工具栏的问号可查看鼠标操作和快捷键。
- 节点卡片展示后端配置。默认高度随配置展开。手动调小卡片后，可在卡片内滚动。转写节点提供进入统一字幕查看页的入口。
- 任务队列列出本机 WebUI 运行记录。点击任务可以查看状态、停止节点、控制台输出和字幕。「清空队列」移除已结束记录，保留正在运行的任务和本机产物。
- 节点位置、大小、折叠、锚点和当前视图在同一个浏览器中自动保留。升级时可从该浏览器最后使用的旧版布局恢复画布。
- 查看任务运行状态、错误提示和节点产物就绪状态。节点参数和撤销／重做会锁定到本次运行结束。

快捷键：`F` 总览，`1` 定位选中，`Ctrl / Cmd Z` 撤销，`Ctrl / Cmd Shift Z` 重做。输入框内保留原生文字编辑快捷键。移动端也可通过顶部的「任务队列」打开抽屉。

## 节点配置范围

| 节点 | 配置来源与操作 |
| --- | --- |
| `probe_input` | 编辑音频流和视频流的绝对索引。留空使用后端自动选择。 |
| `asr_diarize` | 编辑本地 Whisper 模型目录、视频时长上限、音频复识别、Community-1 缓存目录与设备、说话人数量、区分超时和语义复核设置。Community-1 Python 继承当前环境，卡片只读展示该项。 |
| `build_blocks` | 只读展示正式分块跨度和默认术语表，沿用转写节点已生成的英文分段。 |
| `translate_blocks`、`review_blocks` | 只读展示同一份 DeepSeek 模型及请求超时。模型由 `DEEPSEEK_MODEL` 环境变量或本地 `.env` 提供。 |
| `subtitle_cover` | 选择默认样式、高对比底框、宋体细描边或简约精致，以及仅译文、双语译文在上或双语译文在下。480p、720p、1080p、1440p、2160p 档位按导出画面高度自动匹配。 |
| `tts_align` | 只读展示配音模型、音色方式、播放速度范围与顺延等实际配置。 |
| `b_environment` | 编辑分离/非语言事件模型目录、设备、事件阈值与声音增益。 |
| `mix_background` | 编辑背景混音增益；没有有效环境音时基础流程继续。 |
| `compose_video` | 在 `config/compose_video.toml` 中设置输出分辨率与视频码率档位，CLI 和 WebUI 共用。默认沿用源分辨率，并以源视频流平均码率为编码目标。选定分辨率后，ASS 档位随导出画面高度匹配。配音为模拟时使用源视频原声。 |

字幕风格、语言排布和渐入渐出在选择后自动保存到 `config/subtitle_cover.toml`。渐入渐出默认关闭，开启后淡入和淡出各 120 毫秒。手动编辑该文件后，刷新页面即可加载新值。各节点的可编辑配置在选项切换或输入框失焦后自动保存。配置由 CLI 和 WebUI 的后续真实任务共用。节点模式独立保存到 `config/mock.toml`。工作台执行期间锁定配置写入。模型密钥保留在本机 `.env`。

## 维护与后续接入

`/api/workflow-schema` 从 F 的节点注册表和主图依赖读取拓扑。节点配置接口从后端 Pydantic 模型读取字段、默认值和范围，并使用同一模型校验写入。`web/node-schema.js` 维护节点显示名称、颜色、端口文字和初始位置。新节点的业务参数应在后端实现后再接到配置接口。

画布视图使用浏览器的本地存储。工作流拓扑和运行配置从后端读取。上传、任务队列、日志和字幕均通过 `/api/workflow-runs` 相关接口访问。

## 2026-11-17：链接到成片与主图节点对齐

运行入口仍是唯一的 F 主图，不新增图。界面从 `/api/workflow-schema` 获取11个节点、主图边以及增量名单；节点卡片增加 B/C/D/E 归属与基础版/增量标识。新增 b_environment、mix_background 的中文名称、默认布局及实际参数；定向返工显示模型配置，配音节点只读展示音色方式与变速范围。

使用方法：在「视频输入」选择「YouTube 链接」，粘贴单条原视频地址，点击顶部「运行」。后端创建同一个任务目录，通过标准 CLI 下载到 input.mp4，再自动运行探测、转写、翻译审校、配音、字幕、混音和合成。下载是入图准备，不伪造一个主图节点。下载完成后可预览原视频；成片生成后在节点输出或任务队列下载 MP4。本地 MP4 上传仍可用。工作台默认端口8765；`--port 8766` 可启动另一实例。

接口：

- `POST /api/workflow-runs`，`application/json`，请求体 `{"url":"https://www.youtube.com/watch?v=..."}`；返回202及 job_id。
- 同一路径继续接受 `application/octet-stream` 本地文件上传。
- `GET /api/workflow-runs/{id}`：下载/主图阶段、active_nodes、node_states、completed_nodes、input_ready 和 final_video_ready。
- `GET /api/workflow-runs/{id}/logs`：控制台；`/preview-video`：下载完成后的原片；`/final-video`：可下载成片。

只接受现有下载器支持的单条 YouTube 链接；无效地址、播放列表和任意第三方文件地址在入队前拒绝。下载失败会明确显示失败并释放任务锁，可提交下一项。下载器既有时长、体积和超时限制不变。

运行进度来自同一个 LangGraph 的 tasks 事件：WebUI 调用 `python -m cli ... --report-progress`，CLI 将节点名、开始/结束、时间及是否有增量写入 logs/node-progress.jsonl；不记录输入台词、模型正文或凭据，不更改 GraphState/业务产物。可同时展示背景节点与翻译节点运行。增量返回空增量时显示「未产生增量 · 基础流程继续」，不根据残留文件误报成功。普通 run-input 不带该参数时保持原调用行为。

真实运行仍需安装对应 uv extras，准备 Whisper/Community-1/字幕定位模型，配置翻译服务、配音 API 和所选音色；默认 cloned 音色需当前视频说话人的授权音色记录。链接输入不会自动生成新说话人的克隆授权或账号记录。模型和密钥按项目 README 配置，密钥不通过网页提交。

验证：528 passed、2 skipped、2 deselected、11 subtests passed（18.04秒），日志 tests/tmp/webui-full-20261117.log。测试覆盖链接校验、任务冲突、节点并行进度、增量空返回、下载失败，以及 HTTP提交→标准CLI→F主图→实际FFmpeg音视频与字幕合成→成片下载。识别、翻译、配音和下载在该联通测试中使用固定替身，不是重新完成整片真实模型验收；本轮付费API调用0。页面实测已核对11节点、参数、链接切换与无效链接错误提示。旧 Playwright 全量脚本仅同步拓扑断言，本轮未执行该脚本。


### 兼容网关直连配置

在当前 WebUI 运行目录的本机 `.env` 中设置 `DEEPSEEK_TRANSPORT=api` 和 `DEEPSEEK_BASE_URL=https://gateway.example.org/v1`，密钥写入 `DEEPSEEK_API_KEY`，模型标识写入 `DEEPSEEK_MODEL`。模型名以学校账号实际提供的模型为准，不能默认官网模型名也可用于学校网关。

翻译、审校与配音时长改稿复用同一个文本适配器，现在读取该 URL 并请求 `/v1/chat/completions`，不再固定发往官网。兼容接口不附加官网特有的 thinking 参数。地址可带或不带末尾斜杠，也可提供完整 chat/completions 地址，不会重复拼接。实际密钥只留在本机，网页只读设置不展示密钥。

本轮使用模拟 HTTP 验证自定义主机、路径、鉴权头和模型名传递，相关17项测试通过；未调用真实学校模型，也未验证账号余额或模型可用性。


## 自动音色记录与原片只读复用（2026-11-17）

原声音色复刻由固定程序 nodes.auto_voice_profiles 在已有 tts_align 节点内执行，不依赖 Codex，不新建业务图。WebUI 视频输入的授权勾选只对当前视频和任务生效，换文件/链接/素材即重置。API JSON 可传 authorize_voice_clone: true；文件上传使用 X-Authorize-Voice-Clone: true。CLI 对应 --authorize-voice-clone，调用结束恢复原进程权限值。

本次获准后，程序从各说话人的分段中选10–15秒原声；优先连续片段，必要时只拼接同一人的片段，排除已知跨说话人重叠。样本太短、静音或严重削波时先报错，不发注册请求；这些检查不能保证完全去除背景噪声或识别所有串音。所有参考先校验后再创建音色，每次新增说话人最多发起一次请求，失败不自动追加。临时样本处理后清理。沿用 D 的本机私有 audio/voice_profiles.json，不把账号音色ID传入 GraphState 或提交仓库。

相同源音频摘要、配音账号指纹、模型、地域和人物时间轴时，可从历史 jobs 下复用匹配记录；不覆盖错误来源，也不因缺音色自动切换系统音色。已有部分音色时只补缺少的人。创建音色需上传原声，可能收费，费用与额度不由程序猜测。

共享素材：新下载直接存 media/downloads/<视频ID>/，历史下载原地登记原路径。本地上传首次存 media/downloads/uploads/，任务目录不生成 input.mp4；只有派生音轨和输出保留在任务中。GET /api/video-sources 提供列表；POST /api/workflow-runs 可发送 {"source_id":"列表返回的ID","authorize_voice_clone":true}。只接受列表内ID，不能通过接口伪造任意文件路径。预览与主图读取同一原片。

自动音色流程已按单次授权完成小样验证；账户记录留在本机，不随代码发布。后续功能验证使用模拟接口，不额外产生注册费用。

## 视频预览切换与网页 API 设置（2026-11-17）

字幕查看页预览区右上角可切换原视频/目标视频；目标视频读取当前任务的 final_video，尚无成片时按钮禁用。切换尽量保持播放位置，不额外复制视频。目标视频预览使用 final-video?download=0，原下载接口保留附件下载行为，支持 Range 拖动播放。

顶栏「API 设置」提供翻译接口地址、模型和密钥，以及配音地域、模型、业务空间和密钥。地域可手动填写服务商标识，也提供新加坡/北京/上海建议；格式通过不代表服务商已支持该地域。翻译采用兼容 API 直连，默认提供通用服务地址，具体网关、模型、地域及密钥由使用者在本机填写。

配置仅写本机 .env（密钥及连接参数）和 config/tts.toml（配音模型），保留其余配置。密钥采用密码输入框，GET/保存响应仅返回是否已配置，不返回原值；空白保留，显式勾选清除才移除。表单关闭和保存结束清空输入，不写浏览器持久存储。API 仅接受本机同源请求，响应 no-store，运行中禁止修改；下次主图子进程读取新配置，无需重启。修改接口或地域前请自行核对密钥所属服务；保存不触发真实模型调用。密钥仍是本机 .env 文件中的明文配置，应保管本机文件且不得提交仓库。
