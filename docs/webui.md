# 基于多智能体协作的英文视频本地化系统 · WebUI

## 启动

从仓库根目录运行，无需 Node.js 构建、前端依赖安装或模型密钥。

```bash
uv run --locked python scripts/serve_workflow_ui.py
```

浏览器打开 `http://127.0.0.1:8765/`。如端口已占用，可使用 `--port 8766`，并打开对应地址。重启旧版服务后才能加载新增的 `node-schema.js` 路由。

服务仅监听 `127.0.0.1`。浏览器草稿按地址和端口分别保存；更换端口或机器前，先导出 JSON。

## 本版可以做什么

- 在点阵画布中拖动节点标题移动节点，拖动空白平移，滚轮缩放。
- 使用导航图定位、总览、定位选中、100% 缩放、节点折叠和全屏。
- 从左侧按名称、节点 ID 或成员代号搜索，点击后定位节点。
- 在节点卡片中调整常用参数，在右侧「参数」页编辑完整配置。
- 「预览」页显示字幕、封面样式草图，或最近一次模拟的 JSON 输出。转写节点可在本机浏览器打开 B 的 sentence-v2 `timetable.json`，显示句子数、时间轴和未知说话人数量。
- 「接口」页查看节点职责、输入输出和当前参数 JSON。
- 自动保存到浏览器，支持最近 50 步参数和布局撤销/重做。
- 导出、导入带版本的 JSON 配置，与组员共享草稿。
- 使用讲座 / 教程、双人访谈、快速调试三种参数模板。
- 调用本地 LangGraph 固定模拟示例，回放翻译、审校、返工的真实节点更新。

快捷键：`F` 总览，`1` 定位选中，`/` 搜索，`Ctrl / Cmd S` 保存，`Ctrl / Cmd Z` 撤销，`Ctrl / Cmd Shift Z` 重做。输入框内保留原生文字编辑快捷键。移动端用左上角按钮打开目录，用节点参数按钮打开右侧抽屉。

## 运行边界

界面中的 **118 项参数是可编辑、可保存、可分享的配置草稿**。除浏览器样式预览外，它们尚未交给业务模块执行。

「运行模拟示例」只调用已有的 `translation_demo.build_graph()`，使用固定英文句子、固定模拟模型响应。请求不发送画布参数，不消耗真实模型额度，也不会读取输入框中的视频路径。服务返回完整事件列表后，前端进行回放；它不是实时长任务进度流。

- 11 个节点沿用 `docs/design/workflow.md` 的名称与职责。
- 实线为基本工作流的依赖，虚线单独表示现有模拟示例中的返工。
- 节点位置、折叠只改变显示，不能通过拖拽重连来改变执行拓扑。
- 未实现视频上传、任意节点增删、真实 API 参数执行、任务队列或真实成片下载。
- 模型、设备、音色等配置需业务模块校验可用性。示例选项不代表本机已安装或账号已授权。
- 音色 ID 默认留空。身份区分与音色映射不包含声音克隆，也不包含混音中的人声分离。
- 字幕与封面为 CSS 样式预览；实际字体、断行和产物由后续 FFmpeg / Pillow 模块决定。

本 UI 是独立增量，未修改基础版工作流设计中的边界或团队已有 Pydantic 契约。

## 节点配置范围

| 节点 | 配置数量 | 主要配置 |
|---|---:|---|
| `probe_input` | 7 | 素材引用、任务名、音轨、探测超时、解码检查 |
| `asr_diarize` | 15 | Whisper 模型、设备与精度、词级时间戳、VAD、说话人数量 |
| `build_blocks` | 9 | 块时长、断句停顿、上下文、说话人切分、领域术语表 |
| `translate_blocks` | 11 | 模型、生成参数、超时并发、口播风格、翻译约束 |
| `review_blocks` | 10 | 审校模型、错漏译 / 否定 / 数字 / 术语检查、返工策略 |
| `tts_align` | 12 | TTS、采样率、两种音色映射、语速、时间留白、缓存、响度 |
| `edit_assets` | 9 | 平台、文案语气、标题简介长度、标签、来源与章节 |
| `subtitle_cover` | 15 | 双语顺序、字体字号、颜色描边、安全边距、封面样式与格式 |
| `compose_video` | 11 | 编码器、分辨率、CRF、编码速度、帧率、音频、快速起播 |
| `collect_manifest` | 9 | 文件、时间轴、时长校验、哈希、耗时与调用报告 |
| `package_zip` | 10 | 命名、压缩、文件重名策略、包内内容、复核门槛 |

数字输入有范围与步长限制。最少说话人数不得超过最多人数，目标块时长不得超过最长块时长，最大对齐加速不得超过 1.15。非法编辑会保留上一份有效草稿；导入时还检查版本、节点数量、未知参数、类型、文本长度、坐标范围和文件大小。此校验用于 UI 草稿，不能取代后端校验。

## 维护与后续接入

| 文件 | 职责 |
|---|---|
| `web/index.html` | 工作台结构与可访问控件 |
| `web/workflow.css` | 深色节点画布、侧栏、移动端和预览样式 |
| `web/node-schema.js` | 11 个节点的分组参数、默认值、范围和固定依赖 |
| `web/workflow.js` | 参数表单、画布、草稿历史、导入导出和模拟运行 |
| `scripts/serve_workflow_ui.py` | 本机静态资源和 `/api/demo` |
| `tests/webui.spec.cjs` | 浏览器交互回归检查 |

新增或调整参数优先修改 `node-schema.js`，保持节点 ID 与事实源一致。跨节点约束在 `checkRelations()` 中维护。前端使用 `textContent` 渲染用户文字；不把导入配置作为 HTML 插入。

草稿格式为 `format: video-localizer-ui`、`version: 2`、`execution: configuration-draft`。`nodes.<node_id>` 包含 `x / y / collapsed / params`。这是 UI 文件格式，不是正式 GraphState。浏览器存储键为 `video-localizer.workflow.v2`。

B–E 与 F 接入时，先明确每个参数对应的后端配置字段，再由服务端验证、生成任务配置并调用正式图。模型凭据继续留在本机 `.env`；此界面没有密钥输入项。后续接入真实视频进度时，应使用任务 ID 和事件流替代固定示例回放，并按实际能力更新状态提示。

## 已验证

本版使用本地 Chromium 做浏览器回归检查，覆盖 1600 × 1000 桌面和 390 × 844 移动端。

- 11 节点、13 连线、所有节点参数表与默认值。
- 双向参数同步、范围与跨字段校验、刷新恢复、撤销重做。
- 拖拽、折叠、缩放、导航图和恢复默认布局。
- 导出再导入、参数模板、节点重置、非法参数及未知字段拒绝。
- 实际 LangGraph 模拟事件，以及 HTTP 503 时恢复按钮并给出失败原因。
- 字幕封面预览、用户输入作为纯文本显示、移动端目录与配置抽屉。
- JavaScript 语法检查、Python Ruff、`git diff --check`。

尚未验证真实 ASR、TTS、DeepSeek 请求或视频端到端生成；UI 回归通过不表示这些模块已接入。

可在仓库外准备浏览器测试依赖，避免给 Python 应用引入前端构建要求：

```bash
localizer_test_dir="$(mktemp -d)"
npm install --prefix "$localizer_test_dir" playwright@1.62.1
"$localizer_test_dir/node_modules/.bin/playwright" install chromium
NODE_PATH="$localizer_test_dir/node_modules" node tests/webui.spec.cjs
```

测试要求本地服务已启动。选择其他端口时设置 `WEBUI_URL=http://127.0.0.1:8766`。可选 `WEBUI_SCREENSHOT` 指定 PNG 文件位置，测试会另外保存移动端截图。不需要配置任何模型密钥。
