# 基于多智能体协作的英文视频本地化系统 · WebUI

## 启动

从仓库根目录运行，无需 Node.js 构建、前端依赖安装或模型密钥。

```bash
uv run --locked --extra b-asr python scripts/serve_workflow_ui.py
```

浏览器打开 `http://127.0.0.1:8765/`。如端口已占用，可使用 `--port 8766`，并打开对应地址。重启旧版服务后才能加载新增的 `node-schema.js` 路由。

服务仅监听 `127.0.0.1`。打开工作台后，地址末尾会显示当前项目 ID。在同一台机器和服务端口使用该地址，可以从本机项目文件恢复。

## 运行工作流

在「视频输入」节点选择一段带英语语音的本地 MP4，再点击顶部唯一的「运行工作流」。界面显示视频检查、音轨提取、英文识别和导出状态。英文 SRT 生成后，工作流在尚未接入的「断句与术语」节点报错停止。运行记录和转写节点仅显示英文字幕初稿已保存，文件留在任务目录供后续节点使用。转写调用 B 的 sentence-v2 LangGraph 子流程，采用本地 faster-whisper 英文模型和 B 的分句、时间轴检查。初稿保存在 `jobs/webui/<任务 ID>/b/english.srt`，同目录也保留 `timetable.json` 和 B 的运行产物。

转写子进程默认继承启动 WebUI 的 Python 3.11 uv 环境。启动命令中的 `--extra b-asr` 会安装锁定的转写、分句和解码依赖。系统需能运行 FFmpeg 和 ffprobe。

从 [Systran 英文模型文件页](https://huggingface.co/Systran/faster-whisper-base.en/tree/3d3d5de) 下载 `config.json`、`model.bin`、`tokenizer.json`、`vocabulary.txt` 到 `models/faster-whisper-base.en/`。已有其他本地模型目录时，启动服务可指定 `--asr-model-dir <模型目录>`。依赖与模型就绪后可离线转写，无需 API 密钥。

这个入口每次执行一个任务，支持 MP4，最大 2 GiB、2 小时。它产出英文字幕初稿，画布参数仍为草稿。说话人区分及后续翻译、配音继续由各自的模块接入。任务失败时，界面显示错误，详细记录在该任务的 `runner.log` 中。

## 字幕查看

在工作流中选好本地 MP4 后，切到顶部「字幕查看」即可播放源视频。运行时会关联当前任务，右侧四个页签分别显示各阶段产物。点击字幕块会跳到它的开始时间。播放和拖动进度条会高亮当前字幕，勾选「跟随播放」时列表也会自动滚动。

| 阶段 | 读取来源 |
| --- | --- |
| 初版识别 | B 在复识别与复核前的首版句子检查点，转为内部 `b/initial.srt` |
| 断句处理后 | `subtitles/english_segmented.srt`，当前 B 独立流程使用 `b/english.srt` |
| 首次翻译 | `subtitles/translated.srt`，或按分段 ID 合并 `segments/segments.json` 与 `translated/translated_blocks.json` |
| 反思式终版 | `subtitles/bilingual.srt`，或按分段 ID 合并 `segments/segments.json` 与 `translated/reviewed_blocks.json` |

双语 SRT 沿用每块第一行为中文、后续行为英文的约定。首版识别保存的是 B 已形成的第一版句子，原生 Whisper 词级时间仍由 B 在内存处理。旧任务缺少首版文件或流程尚未到达后续节点时，相应页签显示未生成。当前统一运行入口仍在 B 完成后停止，两个翻译页签要等 C 接入主流程后才会随真实任务产出。

这个页面替代在工作台中单独打开 B 的字幕查看页。每个阶段通过本地 JSON 读取接口展示时间轴，SRT 文件留在任务目录。浏览器会在当前会话恢复最近一次运行任务的视频和字幕。选取另一段视频后会切换上下文，避免把上一任务的字幕配到新视频上。

## 本版可以做什么

- 12 个节点按预设位置展开，主流程从左到右，配音、文案、字幕和封面各有分支。连线默认用一条贝塞尔曲线直接连接源节点的输出端口和目标节点的输入端口，经过其他节点时由卡片遮盖。步骤导航可直接定位节点。
- 鼠标移到连线上，右键添加锚点。拖动圆形锚点调整曲线，再右键该锚点可删除。锚点随项目 JSON 保存，也可撤销或重做。
- 拖动节点标题移动节点，拖动右下角调整宽高。聚焦尺寸手柄后可用方向键微调。拖动空白可平移画布，滚轮可缩放。
- 点击顶部「运行」左侧的「任务队列」，从页面右侧打开抽屉。
- 拖动导航图中的视口框平移画布。画布工具栏还提供总览、定位选中、100% 缩放和全屏。点击画布工具栏的问号可查看鼠标操作和快捷键。
- 节点卡片内部提供完整的分组参数。默认高度随参数展开。手动调小卡片后，可在卡片内滚动。
- 「预览」页显示字幕、封面样式草图，以及英文字幕初稿的就绪状态。转写节点提供进入统一字幕查看页的入口。
- 右栏只显示当前工程的运行任务。点击任务可查看状态、停止节点和详情，并打开该任务的视频与字幕。「清空队列」移除当前工程的已结束记录，保留正在运行的任务和本机文件。旧版未关联工程的记录继续留在任务目录。
- 自动备份工程草稿到本机和浏览器。使用「保存工程」将草稿写入选定的工程文件。支持最近 50 步参数和布局撤销/重做。
- 首次进入工作台显示起始页。点击「新建工程」打开预设节点布局，或点击「打开工程」可按最后打开时间查看已关联本地文件的工程，也可选择现有 JSON。未保存的草稿通过工程会话恢复。
- 已打开的工程显示在画布工具栏左侧，可点击标签切换或点 × 关闭。关闭最后一个工程后回到起始页。新建工程的默认参数和布局由 `web/node-schema.js` 定义。
- 「保存工程」或 Ctrl / ⌘ S 第一次会打开系统文件选择器。选定位置后，后续保存写回同一个 JSON 文件。「另存为」可选新位置。「退出」备份草稿并关闭已打开的工程。刷新会恢复标签及本地文件关联。
- 查看真实工作流的进度、停止节点和中间产物的就绪状态。运行中的节点会高亮，节点参数、工程切换与关闭、撤销／重做会锁定到本次运行结束。

快捷键：`F` 总览，`1` 定位选中，`Ctrl / Cmd S` 保存，`Ctrl / Cmd Z` 撤销，`Ctrl / Cmd Shift Z` 重做。输入框内保留原生文字编辑快捷键。移动端也可通过顶部的「任务队列」打开抽屉。

## 运行边界

节点参数仍作为配置草稿保存。本地 MP4 由「视频输入」节点单独选择，并在运行时送入转写流程。

- WebUI 将原设计的字幕与封面节点拆成「字幕样式」和默认关闭的「封面本地化」。字幕交给视频合成，封面可选分支直接接产物汇总。后端正式节点仍需按 E/F 的交接约定接入。
- 实线为基本工作流的依赖，虚线表示审校返工的规划路线。
- 节点集合和依赖由工作流定义。位置、折叠、尺寸和连线锚点属于各工程的画布视图。
- 工作流入口可接收 MP4，中间字幕只在任务目录留存。工作流中的任意节点增删、翻译配音的真实参数执行及成片下载待接入。
- 模型、设备、音色等配置需业务模块校验可用性。示例选项不代表本机已安装或账号已授权。
- 音色 ID 默认留空。身份区分与音色映射不包含声音克隆，也不包含混音中的人声分离。
- 字幕与封面在浏览器内提供样式预览。字幕预览与 E 的审阅包读取同一份模板配置，实际字体和断行以 FFmpeg / libass 为准。

本 UI 是独立增量，未修改基础版工作流设计中的边界或团队已有 Pydantic 契约。

## 节点配置范围

| 节点 | 配置数量 | 主要配置 |
|---|---:|---|
| `probe_input` | 7 | 素材引用、任务名、音轨、探测超时、解码检查 |
| `asr_diarize` | 15 | Whisper 模型、设备与精度、词级时间戳、VAD、说话人数量 |
| `build_blocks` | 9 | 块时长、断句停顿、上下文、说话人切分、领域术语表 |
| `translate_blocks` | 11 | 模型、生成参数、超时并发、口播风格、翻译约束 |
| `review_blocks` | 10 | 审校模型、错漏译 / 否定 / 数字 / 术语检查、返工策略 |
| `tts_align` | 12 | TTS、采样率、两种音色映射、语速、时间留白、缓存、响度 |
| `edit_assets` | 9 | 平台、文案语气、标题简介长度、标签、来源与章节 |
| `subtitle_render` | 2 | 样式大类、字幕排列。压制根据视频尺寸自动选 720p / 1080p / 2160p 基准 |
| `cover_localize` | 7 | 启用封面、来源、封面预览和改图格式 |
| `compose_video` | 11 | 编码器、分辨率、CRF、编码速度、帧率、音频、快速起播 |
| `collect_manifest` | 9 | 文件、时间轴、时长校验、哈希、耗时与调用报告 |
| `package_zip` | 10 | 命名、压缩、文件重名策略、包内内容、复核门槛 |

数字输入有范围与步长限制。最少说话人数不得超过最多人数，目标块时长不得超过最长块时长，最大对齐加速不得超过 1.15。非法编辑会保留上一份有效草稿；打开 JSON 时还检查版本、节点数量、未知参数、类型、文本长度、坐标范围和文件大小。此校验用于 UI 草稿，不能取代后端校验。

## 维护与后续接入

| 文件 | 职责 |
|---|---|
| `web/index.html` | 工作台结构与可访问控件 |
| `web/workflow.css` | 深色节点画布、侧栏、移动端和预览样式 |
| `web/node-schema.js` | 12 个画布节点的分组参数、默认值、范围和固定依赖 |
| `web/workflow.js` | 参数表单、画布、草稿历史、工程标签页、工程文件和工作流运行状态 |
| `scripts/serve_workflow_ui.py` | 本机静态资源、工程列表与 JSON 读写、工作流任务和字幕预览接口 |
| `tests/webui.spec.cjs` | 浏览器交互回归检查 |

新增或调整参数优先修改 `node-schema.js`，保持节点 ID 与事实源一致。跨节点约束在 `checkRelations()` 中维护。前端使用 `textContent` 渲染用户文字；不把工程配置作为 HTML 插入。

项目格式为 `format: video-localizer-ui` 和 `version: 4`。`nodes.<node_id>` 包含位置、尺寸、折叠状态和参数，`edges` 保存连线，`view` 保存缩放、平移、当前节点、底部面板、字幕页签和最近任务引用。节点和视图发生变化后会自动写入 `jobs/webui-projects/<项目 ID>.json`。用户选择的本地文件由浏览器授权写入，后台 JSON 用于草稿恢复。支持本地文件写入的浏览器（如 Chrome 和 Edge）可原位保存。其他浏览器通过文件上传打开工程，保存时下载 JSON 副本。工程名称保存在 `name`。浏览器按工程 ID 保存备份，并在当前浏览器会话中记住标签页顺序。

项目 JSON 是工作台工程文件。视频、字幕、任务日志和 API 密钥各自留在本机对应位置。跨机器打开同一项目时，配置和布局可以迁移，原任务视频需要另行准备。v2/v3 项目仍可打开，旧「字幕与封面」的设置会按类别迁移到两个节点。旧字幕草稿保留中英文排列，细项改用默认模板。打开旧项目时，已知的旧默认排布会迁移为单行布局，自定义位置会保留。

B–E 与 F 接入时，先明确每个参数对应的后端配置字段，再由服务端验证、生成任务配置并调用正式图。模型凭据继续留在本机 `.env`；此界面没有密钥输入项。后续接入真实视频进度时，应使用任务 ID 和事件流替代固定示例回放，并按实际能力更新状态提示。

## 已验证

本版使用本地 Chromium 做浏览器回归检查，覆盖 1600 × 1000 桌面和 390 × 844 移动端。

- 12 节点、15 连线、所有节点参数表与默认值。
- 双向参数同步、范围与跨字段校验、刷新恢复、撤销重做。
- 拖拽、折叠、缩放、导航图和旧工程默认布局迁移。
- 工程打开、切换、保存、关闭、退出，节点重置与非法工程文件拒绝。
- 工作流在未接入节点停止时报告内部字幕就绪，HTTP 503 时恢复运行按钮并显示失败原因。
- 字幕封面预览、用户输入作为纯文本显示、移动端步骤导航与任务队列抽屉。
- JavaScript 语法检查、Python Ruff、`git diff --check`。

尚未验证真实 ASR、TTS、DeepSeek 请求或视频端到端生成；UI 回归通过不表示这些模块已接入。

可在仓库外准备浏览器测试依赖，避免给 Python 应用引入前端构建要求：

```bash
localizer_test_dir="$(mktemp -d)"
npm install --prefix "$localizer_test_dir" playwright@1.62.1
"$localizer_test_dir/node_modules/.bin/playwright" install chromium
NODE_PATH="$localizer_test_dir/node_modules" node tests/webui.spec.cjs
```

测试要求本地服务已启动。选择其他端口时设置 `WEBUI_URL=http://127.0.0.1:8766`。可选 `WEBUI_SCREENSHOT` 指定 PNG 文件位置，测试会另外保存移动端截图。不需要配置任何模型密钥。
