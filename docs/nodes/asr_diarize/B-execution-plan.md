## 3. B 接口提案

整体规划已经约定 `segment_id / speaker_id / start_ms / end_ms / en`。下列外围字段、命名及函数均为提案，需 F 与受影响模块审核后冻结。

```json
{
  "schema_version": "0.1-draft",
  "asset_id": "demo_001",
  "mode": "mock",
  "duration_ms": 12000,
  "segments": [
    {
      "segment_id": "seg_000001",
      "speaker_id": "SPEAKER_00",
      "start_ms": 1000,
      "end_ms": 3500,
      "en": "This is an artificial example."
    }
  ],
  "chunks": [
    {"chunk_id": "chunk_000001", "segment_ids": ["seg_000001"]}
  ]
}
```

- 时间使用全片起点的整数毫秒，满足 `0 <= start_ms < end_ms <= duration_ms`。ASR 秒数只在适配器边界统一转换，不能混用。
- segment 是短语音/字幕与配音单元；chunk 是供翻译理解上下文的分组，目标约 60–90 秒，不是单条字幕或一个配音窗口。尾块可以更短，超长句的处理规则与 C/F 明确约定。
- 自然句边界与说话人变更都需考虑：一个配音单元不能混入两个说话人。存在不确定词或重叠发言时明确标记待复核，不伪造确定结果。
- `speaker_id` 在全片保持一致；不表示真实身份。单人假设标签、模拟标签与自动区分结果需要在元数据中区分。
- 分块音频的局部时间加回切块偏移；间隔保留。相邻翻译块的上下文引用不得重复加入输出片段。
- ID 在同一份已冻结转写及其下游返工中保持不变。重新转写或重新分段需要新版本，并通知 F 使旧的下游产物失效。
- C 追加 `zh_subtitle / zh_dub`，D/E 继续引用原 ID。下游不得静默改动 B 的时间轴。
- 全片媒体时长用于离线本地化，来自媒体检查；它不是语音最后一句的结束时间。

建议职责接口：素材解析、媒体探测、音频提取、转写与说话人对齐、翻译块分组、CLI 参数解析。F 调用这些接口组成工作流；ASR 与说话人区分保留可替换的模拟/真实适配器。

## 4. 素材与链接入口

- B 登记来源、许可/授权依据、本地位置、内容摘要及是否允许团队使用；尚未确认的素材保持待确认，不作为验收素材。
- 最小素材先用约 30–60 秒清晰单人短片，随后准备约 10 分钟单人、2–3 分钟双人、30 与 60 分钟样片。
- 链接模式依计划从 YouTube ID 查登记表，解析到团队有权读取的 HTTPS 原片。不是任意 YouTube 下载器。
- 提案登记字段：视频 ID、授权依据、HTTPS 原片地址、预期内容哈希（如已知）。带签名的地址与登记文件留本地，日志不记录密钥或 URL 敏感查询参数。
- 未登记链接、文件不存在、无音轨、损坏媒体、下载超时要返回可追踪错误；不得用模拟输出掩盖失败。
- 相同素材的本地/链接输入应能核对来源及内容，缓存不能仅按文件名匹配。具体哈希、下载大小及超时限制在实现前与 F 约定。

## 5. B 的验证与证据

| 检查 | 期望证据 |
|---|---|
| 模拟正常输入 | 输出明确标为 mock；ID、类型、时间范围合法；分块既不漏段也不重复 |
| 异常输入 | 无效路径、未登记链接、无音轨、负时间、倒置区间、重复 ID 的明确错误 |
| 真实短片 | 真实 ASR 原始输出与标准化输出分开保留；人工核对文字与边界，记录差异 |
| 时间轴 | 开头/中段/结尾及切块边界抽查，核验偏移与静音间隔；不假定 ASR 词时间戳精确无误 |
| 双说话人 | 至少 10 处交接的参考与预测标签对照，全片编号一致性；未识别情况如实记录 |
| 接入 F | 同一命令可加载 B 输出；下游返工沿用 ID；续跑是否重新调用 B 由 F 的状态和缓存规则验证 |

保留完整命令、输入哈希、代码提交（仅在实际存在时）、模型版本与参数、运行环境、实际耗时和错误。峰值显存、API 用量和费用未测则写 unknown；模拟调用不算真实模型调用。

原始视频、音频、权重、密钥、检查点与成片不提交 Git。测试使用可共享人工样例。真实任务产物留在忽略目录或团队授权空间。

## 6. 提交与协作方式

建议 B 分支名 `feat/b-media-ingest`，分两次可审核交付：

1. 模拟数据、接口提案、CLI 参数和时间轴校验，加针对单位、ID、偏移和异常输入的必要检查。
2. 真实媒体入口、ASR/说话人适配器、真实样片验证与限制记录。

每次 PR 附输入输出、运行命令、验证结果与未完成范围，交 F 和受影响模块负责人审核。认领 Issue、更新远程状态和推送 PR 由团队按权限执行；本地规划不等于已完成远程操作。

当前还没有模型运行证据。不得宣称 LangGraph 闭环、语音识别、双人配音或压测已经通过。

## 7. 当前优先事项与风险

1. F 先汇总接口与主图骨架，B–E 使用相同样例开展开发，避免每人另定义格式。
2. B 准备素材与本地环境；C/D 同时核对模型权限、可用额度及费用。付费使用另行授权，不以计划中的工具名代替可用性核验。
3. D4–D5 同时接多个真实模型、双入口、双人配音，依赖较多。先完成短片再扩大，失败时记录缺口与责任接口，不把模拟成功充作验收。
4. 30/60 分钟压测开始前设定实际可执行的时间、调用和费用上限；遇到上限停止并保留结果，不自动扩大预算。
5. 阶段延误时由团队调整日期或明确变更验收范围。配音、双入口和双人短片仍是原计划首版目标，不能自行删去。
