# B 的 uv 依赖与真实 utils 验证

2026-11-10。以最新 architecture 的依赖管理规范为准：pyproject.toml 声明、uv.lock 锁定；新增依赖用 uv add，运行与测试用 uv run，不使用 pip，不手改锁文件。

## 依赖组

- `b-asr`：faster-whisper、兼容的 PyAV 16、NumPy、spaCy 3.8、英文模型 en_core_web_sm 3.8.0、yt-dlp 与 yt-dlp-ejs。
- 现有 `speech`：保留团队语音依赖，并补充 B 直接使用的 Torch、Torchaudio、NumPy、Hugging Face Hub 声明；运行 Community-1 时与 b-asr 一同启用。
- `b-legacy`：历史 sherpa-onnx 后端，不是默认 Community-1。
- 英文模型使用官方发布 wheel，来源记录在 tool.uv.sources，版本、来源和哈希由 uv 锁定。模型权重、FFmpeg 和可选 Node 二进制另行准备，不塞入 Python 依赖清单。

所有修改均通过 uv add / uv add --optional 完成，uv 自动更新锁文件；没有手动修改 uv.lock。旧 requirements 快照仅保留历史复现记录，不再作为当前安装入口。

## 标准命令

```powershell
# 基础环境与默认测试；缺少语音 extra 的 B 测试明确跳过
uv sync --locked
uv run --locked pytest tests

# B 识别依赖与完整 B 测试
uv sync --locked --extra b-asr
uv run --locked --extra b-asr pytest tests/nodes/asr_diarize tests/nodes/probe_input

# 包含 B ASR 的全仓库回归
uv run --locked --extra b-asr pytest tests

# Community-1 需要同时启用完整 speech extra
uv sync --locked --extra b-asr --extra speech
```

不要为了测试跳过语音依赖而认为 ASR 已验收；完整 B 验证必须带 b-asr。真实模型测试仍须显式启用 B_RUN_REAL_MODELS，不默认下载或推理。默认配置禁止切换到独立手工安装的 Python，Community-1 子进程继承当前 uv 解释器。

本机之前的 Python 3.12 实验环境保留；本次 uv 使用 `.venv-uv` 中新建的 Python 3.11.18，由 UV_PROJECT_ENVIRONMENT 指定。标准团队命令默认使用 .venv，模型与代码行为相同；本机目录不提交。uv 二进制来自 Astral 官方发布并校验 SHA256；没有通过 pip 安装 uv。
