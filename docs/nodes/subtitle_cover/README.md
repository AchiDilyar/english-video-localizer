# subtitle_cover：最终双语字幕与严格单行

当前规则以用户最新要求为准：每屏中文一行、英文一行，上下视觉长度尽量接近；不要求逐屏严格语义等值。保留两种语言原字词、标点及顺序，不通过删字、改写或截掉尾部来满足宽度。

## 执行流程

先完成中文配音和时长返工，以最终TTS稿及最终中文音轨生成时间依据。英文只能取B原台词，中文只能取实际最终配音稿。C提供双语分句建议，E负责最终视觉分页；语序倒置时允许按原顺序截断，不能再保留旧的两行例外。

config/subtitle_cover.toml启用timing_source=speech、paginate=true、semantic_pairing=true、strict_single_line=true。语义建议是初始内容组织，E严格分页可以进一步拆开原先锁定的长单元，并在display_cues中标记ordered_visual_balance，不冒称逐页语义等值。

实际字体测量超过单行宽度时，中文优先在标点、常见短语边界切，英文优先and、that、while、as等及完整单词边界切。联合选择两语言切点，让上下和前后两屏长度尽量均衡。两种语言同时切成先后显示的片段，完整覆盖原文；不改变配音分组或语速。

时间沿最终中文音频文本片段的进度安排，内部切点含插值；每片时间为正、不交叠、总范围不变。字体仍只有限调整，最终单行、字号宽度及无丢字检查是硬门槛，不能绕过paginate，也不能自动换回两行。无法安全分切的极长单词明确报错，不输出越界或极小字字幕。

## 职能与入口

主图对齐说明见 [localize_video](../localize_video/README.md)。C负责内容、翻译审校和语言建议；D负责声音与时长；E负责最终显示、混音和成片，B提供源台词及环境声音。运行只使用F主图；可选环境音/混音回执见上述说明。

生产入口render_speech_subtitles先获取最终音频字幕，再调用unify_final_cues读取实际稿；render_cue_tracks使用严格字体测量及e_single_line分页。三份SRT、burnin.ass和display_cues使用相同显示片段；英文和中文实际稿分别检查完整覆盖。

## 最新五分钟验证

83屏全部中文一行、英文一行，0换行例外、0越界、0丢字或调序。之前两处两行分别拆为81.520–85.900/85.900–88.500秒，以及285.800–287.712/287.712–289.600秒。实测图片和检查在本机tests/tmp/five-minute-bcde-singleline-20261114/。

历史五分钟实验通过当时的BCDE四阶段LangGraph（该入口现已停用）复用B/C/D同源验证缓存，E真实重跑；182项相关测试通过。字幕、配音、背景及非语言声音均有摘要和来源记录，未额外调用TTS或学校模型。原始英文识别仍有待人工核对项，字幕时间也不等于逐词人工强制对齐验收。

旧两行实验仅作为本地历史基准，不是当前规则。源码以2026-11-17交付分支（本轮按用户授权发布main）交付，设计变更待F确认；历史中间文件不上传。
