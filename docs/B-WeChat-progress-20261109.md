# 可直接发送到微信群的 B 组进度

各位，我这边 B（素材准备与语音识别）的核心功能已基本完成，目前是“独立运行验证完成，等待统一接口适配和下游联调”的状态。

【已完成】
1. 支持本地视频和 YouTube 单视频链接，能够下载完整视频并提取音频。
2. 使用 LangGraph 组织 B 的处理流程；faster-whisper 进行英文转写，按句意整理英文台词与全片毫秒时间戳。长句可拆成语义单元，疑似残句会局部复识别。新流程不保存原始 ASR 分段或词时间戳。
3. 已接入本地 Community-1 说话人区分；按一句话中检测到的主要说话人时长归属，边界附近的小范围冲突不单独阻止分配。
4. 提供台词 JSON、CSV、英文字幕和带视频跳转的人工核对页面，以及代码、测试和运行说明。
5. 已跑通约 43 分钟课堂和约 80 分 47 秒多人节目。后一段输出 901 条台词，883 条获得说话人编号，18 条因无说话人检测覆盖保留未知。14 个模型声音组不等于人工确认的 14 个真人。

【待完成/需要对接】
1. 按 F 最新契约包装 probe_input、asr_diarize 两个节点，统一字段、编号、文件路径和 Pydantic 校验。
2. 请 F、D 确认未知说话人的表示及配音处理方式；不能为了接口非空要求随意指派某个人。
3. F 的公共路径/读写/配置工具到位后，进行接口联调；再与 C、D 验证台词读取、说话人标签和固定音色映射。
4. 验证团队 Python 3.11 环境。当前 B 的独立验证环境是 Python 3.12，不覆盖团队环境。
